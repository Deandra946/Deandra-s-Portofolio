# Sertifikat

Letakkan gambar sertifikat di folder ini. Setelah itu tambahkan import dan datanya pada `src/components/Certifications.tsx`.

Contoh:
```tsx
import sertifikat1 from "../assets/certificates/sertifikat-1.jpg";

const certifications = [
  { title: "Nama Sertifikat", issuer: "Penerbit", year: "2026", image: sertifikat1 },
];
```
